# LX세미콘 월간 리포트 자동화 웹앱

담당자가 매달 원본 자료를 업로드하면 ① 로우데이터(취합) 엑셀 → ② 로우데이터 AD 엑셀 →
③ 월간보고서 PPT를 순서대로 만들어주는 Streamlit 앱입니다.

- 판단이 애매하거나 원본에 없는 값은 절대 임의로 채우지 않고 "⚠ 확인 필요"로 표시합니다.
- 전월 최종본(fn) 파일의 서식·수식을 그대로 복제해 맨 아래에 이번 달 블록만 추가합니다.

## 진행 상황

- ① 로우데이터(취합) — 콘텐츠 Raw Data 5개 시트(뉴스룸/유튜브/인스타그램/페이스북/블로그) 자동화 완료.
  '채널 팔로워' 시트는 (선택) Daily data 파일을 올리면 일별 로그만 자동으로 채웁니다(상단 월간
  요약표는 채널마다 수식이 달라 자동화 대상이 아니며 수기 확인이 필요합니다). '월간 SNS 운영 수치'
  시트는 이번 버전에서는 건드리지 않고 그대로 보존합니다.
- ② 로우데이터 AD — 준비 중
- ③ 월간보고서 PPT — 준비 중

## 개인정보 처리 방식

- 업로드한 파일은 **서버 디스크에 저장되지 않고, 메모리에서만 처리**됩니다.
- 결과 엑셀도 서버에 저장하지 않고 메모리(`BytesIO`)에서 생성해 바로 다운로드로 전달합니다.
- 세션(브라우저 탭)이 종료되면 업로드했던 파일과 처리 결과는 서버 메모리에서 함께 사라집니다.
- Streamlit은 브라우저 세션마다 독립된 서버 세션을 사용하므로, 여러 명이 동시에 접속해도
  서로의 업로드 파일이나 처리 결과가 섞이지 않습니다.

## 로컬 실행

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 저장소를 GitHub에 푸시합니다 (데이터 파일은 `.gitignore`로 자동 제외됨).
2. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인합니다.
3. "New app" → 이 저장소 선택 → Branch: `main`, Main file path: `app.py` 선택 후 Deploy.
4. (선택) 접속 비밀번호를 걸고 싶다면 Streamlit Cloud 앱 설정의 Secrets에
   `APP_PASSWORD = "원하는비밀번호"` 를 추가합니다. 설정하지 않으면 비밀번호 없이 누구나 접속됩니다.
5. 배포가 끝나면 생성된 링크(`https://<앱이름>.streamlit.app`)를 팀원에게 공유하면
   설치나 로그인 없이 바로 파일을 업로드하고 결과를 받을 수 있습니다.

## 알려진 제한 사항

- 콘텐츠 발행리스트 / 캠페인 플랜 / 네이버 블로그 실적 / 버즈빌 리포트 / 뉴스룸 URL별 조회수 /
  채널별 팔로워 월말 수치의 정확한 원본 포맷은 아직 실물 샘플로 전량 검증되지 않았습니다.
  실제 파일 형식이 다르면 파서가 "확인 필요"나 명확한 오류 메시지로 멈추도록 만들어져 있으니,
  실사용 중 형식이 다르다는 오류가 나오면 알려주세요.
